# 网易云评论检索器 · 使用说明

> **一句话**：双击文件夹里的启动文件 → 浏览器自动打开 → 填歌名和用户 ID → 点「开始检索」。
>
> 全程在你自己的电脑上运行，不接入任何 AI，也不把数据传到任何第三方服务器。

---

## 一、开始之前

### 你需要准备什么

| 项目 | 要求 |
|---|---|
| 电脑 | Windows / macOS / Linux 都可以 |
| Python | **3.8 或更高版本**（必需，但不需要装任何第三方库） |
| 网络 | 能正常打开 `music.163.com` |

**不需要**执行 `pip install`。
本项目把加密和网络这两块都做了自带兜底实现，所以只要电脑上有 Python，解压出来就能直接跑。

### 三步开始用

**第 1 步：完整解压**

把整个文件夹解压到一个普通目录（例如桌面）。
⚠️ 不要只把其中某几个文件拖出来单独运行，它们是互相依赖的。

**第 2 步：双击启动文件**

| 系统 | 双击这个文件 |
|---|---|
| Windows | `启动界面.bat` |
| macOS | `启动界面.command` |
| Linux | 在终端里执行 `./start.sh` |

> ### ⚠️ macOS 双击打不开？先看这里（这是最常见的问题）
>
> 如果双击后出现下面**任何**一种情况 ——
>
> * 「无法打开，因为来自身份不明的开发者」
> * **「已损坏，无法打开。你应该将它移到废纸篓」**
> * 双击后窗口一闪就消失 / 完全没反应
>
> —— **文件没有损坏，也没有病毒，别删。**
>
> 原因是 macOS 的 Gatekeeper 机制：文件只要经过**微信 / QQ / 网盘 / 邮件**传递一次，
> 系统就会给它打上「隔离标记」（`com.apple.quarantine`），
> 于是拒绝运行里面的脚本。这跟文件内容无关，换任何工具都会遇到。
>
> **放行方式（任选一种，只需做一次）：**
>
> * **方法一 · 最简单**：在 `启动界面.command` 上**点右键 → 打开 → 弹窗里再点「打开」**。
> * **方法二 · 万能**：打开「终端」App，输入 `xattr -dr com.apple.quarantine `（**末尾有一个空格**），
>   然后把**整个文件夹拖进终端窗口**（路径会自动补全），回车。
>   再回去双击启动文件就行了。
>
> 放行一次之后，启动器会自动把整个文件夹的隔离标记一起清除，
> 同目录下的其他脚本就不必再单独处理。
>
> 💡 **Windows 用户**若看到「Windows 已保护你的电脑」（SmartScreen 蓝框）：
> 点「更多信息」→「仍要运行」即可，同样只需一次。

**第 3 步：等浏览器自己打开**

界面地址是 **http://127.0.0.1:8765/**。如果浏览器没有自动弹出，手动在地址栏输入这个地址即可。

> 🔺 **那个黑底（或白底）的命令行窗口不要关掉** —— 它就是服务本体。
> 关掉窗口 = 停止服务；想在停止前先看结果，让它开着就行。

## 二、界面上怎么操作

界面是四步式流程，从上到下依次做：

### 第 1 步 · 填条件

**歌曲区**（可以多行混写，一行一个）：

| 写法 | 例子 | 说明 |
|---|---|---|
| 歌名 | `向阳而生` | 走搜索接口，会返回候选列表给你勾选 |
| 歌曲 ID | `2006484446` | 直接定位，最快最准 |
| 网易云链接 | `https://music.163.com/song?id=2006484446` | 歌曲 / 歌单 / 专辑链接都能识别 |
| 带类型前缀 | `album:156507145` | 用于消歧，见下方「注意事项」 |

**用户区**：

- **用户 ID（uid）**：最可靠，强烈建议填这个
- **用户昵称**：只有拿不到 uid 时才用（重名很多）
- 两个都填 = 满足任一条件就算命中；可勾选「模糊匹配」让昵称按包含关系匹配

> **怎么查 uid？**
> 在浏览器打开这个人的网易云主页，地址栏里 `music.163.com/user/home?id=` 后面那串数字就是 uid。
> （很遗憾，网易云的"按昵称搜用户"接口在未登录状态下永远返回空，所以昵称搜不到人是正常的，不是工具坏了。）

### 第 2 步 · 确认曲目

解析出的候选歌曲会列出来，默认全选。确认无误后继续；不想检索的可以取消勾选。

### 第 3 步 · 开始检索

点「开始检索」后，会实时显示每首歌的：

- 已扫描条数、已翻页数
- 命中条数、耗时、速率
- 是否疑似被服务端限流截断（会标红提示并自动降速重扫）

随时可以点「停止」，已拿到的结果不会丢。

### 第 4 步 · 看结果 / 导出

命中评论会以表格展示，包含：评论内容、时间、点赞数、IP 属地、命中原因、楼中楼引用。

可导出两种格式：

- **CSV** —— 已带 BOM，用 Excel 直接打开不会中文乱码
- **JSON** —— 需要程序化处理时用

## 三、如果电脑上没有 Python

启动脚本会明确告诉你"未找到 Python"，并给出安装方式。手动操作如下：

**Windows**

1. 打开 <https://www.python.org/downloads/> 下载安装包
2. 安装界面**第一步务必勾选 `Add python.exe to PATH`**，这一步漏了会找不到命令
3. 装完重新双击 `启动界面.bat`

**macOS**

1. 打开 <https://www.python.org/downloads/> 下载安装包，一路「继续 / 安装」
2. 或者在「终端」里执行 `xcode-select --install`（装 Xcode 命令行工具，自带 Python 3）
3. 装完重新双击 `启动界面.command`

**Linux**

```bash
sudo apt install python3      # Debian / Ubuntu
sudo yum install python3      # CentOS / RHEL
```

## 四、出问题时，先跑「环境自检」

文件夹里有专门的自检入口，它会检查 Python 版本、加密与网络通道、前端文件是否齐全，并实际探一次能否连上网易云：

| 系统 | 双击这个 |
|---|---|
| Windows | `环境自检.bat` |
| macOS | `环境自检.command` |
| 命令行 | `python web/server.py --check` |

自检结论为「环境就绪」时，说明问题不在运行环境，而在输入条件或网络策略上。

## 五、常见问题

| 现象 | 原因与解决办法 |
|---|---|
| 双击后窗口一闪而过 | 先跑一次「环境自检」。若是没装 Python，按第三节处理 |
| **macOS 提示"已损坏，无法打开"或"来自身份不明的开发者"** | **文件没坏**。这是微信 / 网盘 / 邮件传递带来的「隔离标记」，见第一节顶部那段「macOS 双击打不开？」。按方法一或方法二放行一次即可，之后启动器会自动把整个文件夹的标记一并清掉 |
| macOS 提示"没有执行权限" | 用系统自带的「归档实用工具」解压一般不会有此问题。若出现，先执行 `xattr -dr com.apple.quarantine <文件夹>`，再 `chmod +x *.command` |
| 从微信 / QQ 收到的 zip | 解压后按上一条放行即可。想彻底避免，可让对方用邮件 / U 盘传递，或用「访达 → 文件 → 压缩」重新打包后发送 |
| Windows 蓝框"Windows 已保护你的电脑" | 点「更多信息」→「仍要运行」，只需一次 |
| 想把工具拷到 U 盘 / 发给别人 | 直接把**整个文件夹**拷过去即可（约 100KB），也可以压缩成 zip 再发。对方的电脑只要有 Python 就能跑，不需要装任何东西 |
| **界面能打开，但点「解析」没反应 / 一直转圈** | 九成是**后端服务没在跑**。看界面右上角：显示「已连接后端 …」才正常；显示「未连接后端服务」说明那个启动终端窗口已经被关掉了。重新双击「启动界面」并**让那个窗口一直开着**，再刷新本页。页面本身不联网，没有后端什么都做不了 |
| 重复双击了启动脚本 | 会自动**探测已在运行的实例并直接复用**（打印「服务已经在运行」），不会堆出好几个窗口。想重启就先回到原窗口按 Ctrl+C 停掉 |
| 提示端口被占用 | 不用管，程序会自动往后顺延端口；也可以 `./start.sh 9000` 指定 |
| **选中的曲目很多，跑了很久还没结束** | 「最大页数」默认 `0` 表示**不限量、抓到抓完为止**。100 首歌可能要几十分钟。想先看效果，把它设成 `1`~`2`，或先只勾选 1~2 首 |
| 昵称搜不到人 / 搜出 0 条 | 未登录状态下网易云的搜用户接口恒为空。请改用 uid |
| 某个 ID 解析出来是别的东西 | ID 有歧义（见下方「注意事项」），加前缀或改用完整链接 |
| 检索结果是 0 条 | 该用户确实没在这首歌下评论过；也可能 Ta 是"只看不评"的潜水用户 |
| 进度到某个整数就停住 | 服务端限流。程序会检测到并自动串行重扫，耐心等一下 |
| 提示"疑似被截断" | 这是保护机制在起作用，它会自动重扫该曲目，完成后以重扫结果为准 |
| 电脑睡眠 / 断网后卡住 | 恢复网络后点「停止」再重新开始即可，已抓到的结果仍在 |
| 想让局域网其它设备访问 | 默认只监听本机是出于安全考虑，如需开放可加 `--host 0.0.0.0`（注意风险） |

### 关于 ID 歧义的注意事项

网易云的**歌曲、歌单、专辑 ID 长得一模一样**，没有任何位数规律。纯数字输入会按
**歌曲 → 歌单 → 专辑** 的顺序试探，界面上会写明"已按 XX 解析"。

想精确指定时：

- 加前缀：`song:123456` / `playlist:123456` / `album:123456`
- 最保险：直接把网页端地址栏里的**完整链接**粘进去

## 六、数据在哪里

**网页模式全程只在内存里处理，不往磁盘写任何东西。**

- 检索过程中抓到的评论只存在于运行中的进程内存里
- 结果是你在界面上点「导出」时，由浏览器下载到你指定的位置
- 服务一停，内存里的数据就没了

这意味着两件事：**隐私上很干净**（不留痕迹），但**导出要记得点**（关掉窗口就找不回来了）。

命令行模式（第 7 节）则是另一回事，它会把数据落盘到 `output/` 目录，方便做大批量断点续传。

## 七、命令行用法（可选，给进阶用户）

网页界面之外，也保留了完整的命令行工具：

```bash
# 环境自检
python web/server.py --check

# 抓某个歌单里所有歌的评论，筛出指定用户的发言
python run.py --playlist 3778678 --user 123456789

# 只抓某首歌，限 2 页
python run.py --song 2006484446 --user 123456789 --max-pages 2

# 只看有哪些参数
python run.py --help

# 离线自检（不联网，验证加密与分页逻辑，共 45 项）
python tests/smoke_test.py
```

命令行模式会把数据存进 SQLite（`output/<任务名>/comments.db`），支持断点续传与去重。

## 十、为什么它不需要联网装依赖

原本这类项目要装 `requests`（HTTP）和 `pycryptodome`（AES 加密）。换台电脑就得
先有网、有能用的 pip、还得能连上 PyPI —— 任何一环断了就卡住。

这里把两者都变成了**可选的加速项**：

| 组件 | 装了就用 | 没装则用 |
|---|---|---|
| HTTP 通道 | `requests` | 内置 `http_compat.py`（基于标准库 `urllib`，接口对齐 requests） |
| AES 加密 | `pycryptodome` | 内置 `_aes.py`（纯 Python 实现） |

两条路径产生的密文**逐字节一致**，并用 FIPS-197 与 NIST SP 800-38A 官方测试向量校验过，
所以回退不是"降级凑合"，而是等价的另一条路。

想看当前用的是哪条路径，跑一次 `环境自检` 即可，它会打印：

```
AES 加密后端   : 内置纯Python实现
HTTP 通道后端  : urllib(标准库)
```
